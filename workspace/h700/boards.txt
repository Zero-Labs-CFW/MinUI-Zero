# THE H700 BOARDS: the one list. The image build ships it as .system/h700/boards.txt; everything reads it there or here:
#   image build      tools/build-h700-stripped.sh, tools/h700-image/oneimage.py, verify-image.py
#   device scripts   minui-frontend.sh, MinUI.pak/launch.sh, bin/suspend, boardpick.sh, Device Sync.pak
#   platform.c       boards.h, generated from this file by workspace/h700/gen-boards.sh at build time
# A new board is a row here plus its pinned assets (tools/h700-image/assets.sha256).
#
# id     muOS board/name. DEVICE is the id without "rg35xx-" (plus, h, pro, sp, rg40xx-h, ...).
# type   the screen-type group the first-boot picker shows and cycles through, in order (boardpick.sh): boards in
#        one group share a panel setup, and the first of each group stands in for it while it is tried.
# w h    the frame the UI renders (FIXED_WIDTH/HEIGHT): 720x720 Cube, 720x480 RG34XX/RG SP, else 640x480.
# rot    degrees the frame turns onto a portrait panel (h700_rotate): the RG28XX panel is 480x640, direction
#        unmeasured on our chain.
# rows pad  menu rows and padding (the Cube's square panel: 8 and 40, as upstream rg35xxplus).
# hz     panel refresh minarch paces to (MINARCH_PANEL_FPS). Plus/H MEASURED 59.9777 (panelprobe 2026-08-04); the
#        Pro boots the 3f2fa25 package with the Plus/H timings. The rest are pixel clock / (htotal x vtotal) from
#        the tree each board boots, not measured: SP and 40XX (audit 2026-09-25), RG34XX family 54 MHz /
#        (1679 x 536), Cube 48 MHz / (1060 x 755), RG28XX 24 MHz / (584 x 685).
# flags  comma list, "-" for none:
#          lid        hall lid on PE7 (platform.c PLAT_initLid, bin/suspend lid_shut)
#          lpddr3     needs an LPDDR3-primary boot0 (the build fails closed without one)
#          plusboot0  Anbernic's stock boot0 equals the Plus's, so its own is optional (Knulli dumps, 2026-09-25)
#          sleep      deep sleep proven on this board (suspend and wake on hardware)
#          pwm3       rumble on pwm3; the shared kernel's axp2202 'moto' drives pwm2 (2026-09-25 research)
# pins   GPIOs the frontend drives at boot, "pin:level" comma list, "-" for none
# label  the rest of the line: the picker, About (as "Anbernic <label>") and Device Sync name the board with it
#
